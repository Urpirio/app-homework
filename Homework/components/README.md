# Components

This directory contains all React components for the animated splash and login feature.

## Structure

- **splash/**: Components for the splash screen
  - `AnimatedLogo.tsx`: Logo with entry/exit animations
  - `SplashContainer.tsx`: Container with theme support

- **login/**: Components for the login screen
  - `LoginForm.tsx`: Main login form component
  - `AnimatedInput.tsx`: Input field with animations
  - `AnimatedButton.tsx`: Button with visual and haptic feedback
  - `ErrorMessage.tsx`: Error message with shake animation
  - `LoadingIndicator.tsx`: Loading spinner

- **shared/**: Shared components used across screens
  - `ThemedView.tsx`: Container with theme support
  - `KeyboardAvoidingContainer.tsx`: Container that handles keyboard
