# Types

This directory contains TypeScript type definitions.

## Files

- `auth.ts`: Authentication-related types (LoginCredentials, User, UserRole, FormState)
- `project.ts`: Project and Task types
- `theme.ts`: Theme-related types (Theme, ColorScheme, etc.)
- `submission.ts`: Submission types matching Prisma Submission model
- `message.ts`: Chat message and attachment types matching Prisma Message/Attachment models
- `library.ts`: Book, BookLoan, and BookCategory types matching Prisma library models
- `ticket.ts`: Support ticket types matching Prisma Ticket model
- `review.ts`: Review types matching Prisma Review model
- `schedule.ts`: Schedule types matching Prisma Schedule model
- `institution.ts`: Institution types matching Prisma Institution model
- `classroom.ts`: Classroom types matching Prisma Classroom model
- `notification.ts`: Notification and NotificationPreferences types matching Prisma Notification model
